# Project instructions

## Language

English is the project language for all code and documentation: identifiers,
comments, log and error messages, tool names and descriptions, MCP server
instructions, and every Markdown file.

## Before you write

- Writing, changing or reviewing code: follow `docs/coding-standards.md`.
- Naming a domain concept in code, docs or tool text: use the term from
  `GLOSSARY.md`, and add a term there when a new one is settled.
